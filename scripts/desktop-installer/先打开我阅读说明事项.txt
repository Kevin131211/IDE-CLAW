                    IDE Claw 桌面端 - 使用指南
================================================================

  欢迎使用 IDE Claw！
  本文档会用 1 分钟时间告诉你怎么用这个 zip 里的所有文件。

================================================================
[一] 我只想用 IDE Claw 收消息（最常见）
================================================================

  操作：双击 ide_claw.exe

  就这一步，结束。

  会发生什么：
    - 桌面端启动，会停留在系统托盘
    - 自动监听本机的 127.0.0.1:13800 (本地 IPC 端口)
    - 接到消息会弹通知 + 在窗口里显示

  关闭：
    - 点窗口 X 不会真退出，会缩到右下角托盘
    - 右键托盘图标 -> "退出" 才是真退出

================================================================
[二] 我想让 Cascade (Windsurf 的 AI) 主动推消息给我
================================================================

  这种场景下你需要 Python 环境 + dialog.py 脚本。
  我们准备了一键安装脚本：

  操作：双击 setup-cascade.bat

  这个 .bat 会做：
    1. 检测你电脑里有没有 Python
    2. 没有的话用 winget 自动装 Python 3.12
    3. 安装 dialog.py 需要的两个 pip 包
       (requests + websocket-client，约 5MB)
    4. 完成

  装完之后，dialog.py 在哪？
    - dialog.py 不在这个 zip 里，它是项目源码的一部分
    - 完整项目下载：https://push.shoot-game.cn/
    - 路径：项目根目录\cascade\dialog.py

[四] 常见问题 FAQ
================================================================

  Q: 双击 ide_claw.exe 没反应？
  A: 可能被杀软拦了。试着右键 -> 属性 -> "解除锁定"。
     或者把整个文件夹加到杀软白名单。

  Q: setup-cascade.bat 提示 "winget 不可用"？
  A: 你用的是旧版 Windows 10。手动去 https://www.python.org/
     下载安装 Python 3.10+，安装时勾选 "Add Python to PATH"。
     装完再回来双击 setup-cascade.bat 装依赖。

  Q: pip install 卡死/报超时？
  A: 国内网络问题。在 cmd 里跑：
     pip install -i https://pypi.tuna.tsinghua.edu.cn/simple requests websocket-client

  Q: 桌面端总在右下角托盘里关不掉？
  A: 右键托盘图标，选"退出"。点窗口 X 是最小化到托盘，不是退出。

  Q: 桌面端连不上服务器？
  A: 检查 https://push.shoot-game.cn/api/health 在浏览器里能否访问。
     如果不能，就是服务器或你的网络的问题。
